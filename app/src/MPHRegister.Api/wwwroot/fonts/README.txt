Carlito (SIL Open Font License 1.1, see Carlito-OFL.txt): a free font with the same character widths as Calibri,
from https://github.com/googlefonts/carlito. Bills use Calibri when the computer has it and Carlito otherwise,
so a bill is laid out the same on every computer, with no internet. Subset to Latin, punctuation and currency (incl. ₹).
