      Settings

      Import an inward register workbook

      Reads the Main sheet of a monthly workbook. Your workbook is never changed. A backup of the data file is taken before anything is imported.

      Importing a month that is already in the app updates it: new rows are added, what changed in the workbook since the last import is applied, what was changed in the app is kept, and entries no longer in the workbook are removed (never billed ones). Check file lists every new and updated entry first; after importing, the Register's Last import filters show them.

      Import an AAWAK workbook

      Reads the Main sheet of the gate's monthly AAWAK workbook (and its hidden Details lists). Your workbook is never changed. A backup is taken before anything is imported.

      Import a newer copy of the same month as often as you like: rows are matched by AAWAK NO, new rows are added, what changed in the workbook is applied and what was changed in the app is kept. Each row is then linked to its inward slips.

      Import bills from the Excel bill workbook

      Reads every filled bill on the Main sheet, checks each total, and links bill lines to inward entries so they are not billed again. Your workbook is never changed.

      Re-check links of imported bills

      Matches every bill imported from Excel to the inward register again — after correcting the register or giving sister firms a group in Masters → Parties. The bills and their totals stay as they are; only the inward entries they are linked to change. A backup is made before saving.
